# Cricket ScoreCard

An Expo React Native conversion of the supplied browser-based React scorecard.

## Run the app

```bash
npm start
```

Scan the QR code with Expo Go, or press `a` for an Android emulator. On Windows, use Expo Go or Android for development; local iOS builds require macOS.

## Included

- Three-step match and roster setup
- Ball-by-ball scoring, extras, wickets, strike rotation, and bowler changes
- Automatic innings and match completion
- Match history stored with AsyncStorage
- Match summaries and player-of-the-match calculation
- Player statistics, profiles, comparisons, head-to-head records, and fantasy rankings
- Editable fantasy-points settings

The original pasted source ended partway through its `Match` component. Missing screens and scoring behavior were completed based on the state shape and menu routes present in that source.
